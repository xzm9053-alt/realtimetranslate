一、软件核心特色
────────────────
「实时翻译」是一款专为 Android 打造的高性能全场景实时翻译工具。无论是在线生肉追番、生肉游戏、外语会议、外语短视频，还是离线文档阅读，都能提供极致顺滑的双语体验：

  1. 端侧离线优先：
     - 内置阿里 SenseVoice 语音识别模型（int8 离线模型，约 240MB），离线听写零延迟、零流量消耗、数据不出设备。
     - ML Kit 离线 OCR 文字识别引擎，框选屏幕即可毫秒级取词。
  2. 系统级音频内录：
     - 支持直接内录手机系统中其他 App 播放的声音（YouTube、Bilibili、Twitter、Netflix、游戏等），无需外放，插耳机或静音也能翻译。
  3. 丝滑悬浮窗与动效：
     - 悬浮窗贴边折叠收缩为半球，60fps 帧同步拉出展开；支持防误触全局穿透锁定与轻量手势工具栏。
  4. 多格式独立工具箱：
     - 支持 PDF / Word / Excel / PPT / TXT / Markdown 六大文档原位排版翻译；
     - 本地视频提取音轨生成时间戳字幕，支持原画画质压制烧录 MP4。
  5. 丰富引擎与情境风格：
     - 支持微软/谷歌免密直连、DeepSeek（闲时半价）、阿里百炼、智谱 GLM、Gemini 以及通用 OpenAI 兼容接口；
     - 支持二次元动漫、游戏、商务、学术、影视等五大领域语气风格。


二、系统要求与权限准备
──────────────────────
  · 运行环境：Android 10 及以上系统（推荐 Android 12~15）
  · 建议内存：4GB 及以上（SenseVoice 模型占用约 300MB 内存）

首次使用时，请按提示授予以下权限：
  1. 悬浮窗权限（「显示在其他应用上层」）：
     - 必需，用于展示悬浮字幕窗、屏幕取词球与译文气泡。
  2. 录屏授权（MediaProjection）：
     - 必需，用于内录系统内部音频流（不录制手机屏幕图像），或屏幕取词时获取截帧。
     - 注意：系统弹窗提示「开始录制或投屏」时勾选「不再提示」并点「立即开始」。
  3. 麦克风权限（录音权限）：
     - 可选，当声音来源选择「麦克风」或「混合录音」时使用。
  4. 通知权限（Android 13+）：
     - 用于前台服务常驻，防止在后台时被系统意外回收。
  5. 后台运行与电池优化（重要）：
     - 小米 / HyperOS / 华为 / OPPO / vivo 等系统，建议前往「设置 ➔ 应用管理 ➔ 实时翻译」：
       开启「自启动」并将省电策略设为「无限制」，防止锁屏或长时间切换后台被系统杀后台。


三、核心功能：声音同传（实时字幕）
──────────────────────────────────
适用于看外语视频、听外语音频、游戏语音、在线跨国会议或实时外语对话。

【启动步骤】
  1. 打开主界面，顶部切换至「🎙️ 声音同传」面板。
  2. 选择源语言与目标语言（中间提供「⇄」按钮可一键对调双向语言）。
  3. 选择声音来源：
     · 媒体音（推荐）：直接捕获手机内正在播放的声音，戴耳机或静音播放均可正常翻译。
     · 麦克风音：录制环境人声或对着手机外放的声音。
     · 混合录制：同时录制系统内放音与麦克风环境音。
  4. 点击下方的「▶ 开始实时翻译」大按钮。
  5. 屏幕即刻浮现双语字幕悬浮窗，开始播放外语音频即可看到文字如流水般涌出。

【离线听写模式（仅识别不翻译）】
  在中央语言卡片中打开「仅识别（不翻译）」开关：
  - 目标语言变为「（不翻译 · 仅听写）」，主按钮变为「▶ 开始实时听写（仅识别）」。
  - 100% 运行在手机本地端侧，零 API 消耗、零网络请求、零延迟，适合快速语音打字、演讲速记与听写。

【字幕外观定制】
  在首页下方展开「字幕外观微调」抽屉，支持所见即所得实时调整：
  - 双语三态显示：原文+译文（默认）、仅译文、仅原文。
  - 字体大小：12sp ~ 32sp 滑块平滑调节。
  - 背景透明度：0% ~ 100% 透明度调节。
  - 调色盘：提供 14 种预设高对比度色彩，原文与译文可分别独立上色。


四、核心功能：屏幕取词翻译（OCR 气泡）
──────────────────────────────────────
适用于玩生肉外语游戏、阅读外文漫画、浏览未翻译的社交动态或视频内嵌字幕。

【使用步骤】
  1. 首页顶部切换至「🔍 屏幕取词」面板，点击「▶ 启动屏幕取词」。
  2. 屏幕浮现全屏选区遮罩：
     - 单指拖动矩形内部：平移选区位置；
     - 拖动四角控制点：调整选区矩形大小；
     - 在空白处长按拖动：重新拉出一个全新矩形框。
  3. 框住要翻译的屏幕文字后，点击右下角「开始翻译」。
  4. 屏幕边缘立即生成取词悬浮球，译文自动在球旁气泡中展现。

【取词专属手势】
  · 暂停 / 继续：单击一下悬浮球，即可暂停屏幕采集与翻译（保留当前译文，适合长句细读）；再次单击恢复。
  · 快捷菜单：长按悬浮球 500ms，弹出四合一操作菜单：
      ① 暂停 / 继续采集
      ② 重新框选区域
      ③ 隐藏 / 显示红色取词外框（玩游戏看剧不遮挡视野）
      ④ 停止取词会话
  · 选区微调：无需重新框选，直接按住屏幕红色取词框右下角的半透明圆点：
      - 快速拖动：缩放选区大小；
      - 长按 500ms 后拖动：平移整框位置。
  · 智能避让：悬浮球与译文气泡拥有智能避让算法，永远自动躲到取词区域外部，杜绝自己遮挡自己导致的画面循环抖动。
  · 横竖屏自适应：手机横竖屏旋转时，选区自动依屏幕坐标系自适应映射重算，无需重新框选，翻译绝不中断。


五、悬浮窗与悬浮球完整手势指南
──────────────────────────────
【悬浮字幕窗】
  · 移动位置：按住窗口顶部的浅色细横条（Grabber）任意拖动。
  · 缩放大小：按住窗口右下角的斜角三角圆点拖拽，自由调整视窗宽高（文字自动按容器重排）。
  · 贴边折叠：将窗口拖拽至屏幕左边缘或右边缘松手，窗口会以减速阻尼动画自动收起为屏幕边缘的「贴边半球」。
  · 贴边移动：按住半球沿屏幕左侧或右侧边缘上下滑动，可换边，拖动过程中不会意外展开。
  · 丝滑拉出：从屏幕边缘将小球向屏幕内拉出，伴随 60fps 帧同步与触觉微振动，半球平滑展开为完整圆球。
  · 轻量操作栏：单击窗口顶部 Grabber 横条，展开四合一快捷工具条：
      ① 📋 一键复制：将当前屏幕累积的全部译文拷入剪贴板；
      ② 🔄 显示模式：在「双语对照 / 仅译文 / 仅原文」之间一键轮转；
      ③ 🔒 穿透锁定：启用 FLAG_NOT_TOUCHABLE 全局防误触模式，窗口半透明化，所有触控直接穿透到底层应用（如看全屏游戏或视频时防误触）。屏幕边缘会保留微型解药胶囊，长按 1 秒退出穿透；
      ④ ✕ 退出会话：快速结束当前翻译任务。

【取词悬浮球与气泡】
  · 译文气泡整体拖动：按住译文气泡边缘可将其固定在屏幕任意心仪位置，不会被新句子拉回。
  · 长译文内部滚动：长句或段落过长时，在气泡内部竖向滑动优先滚动浏览文本。
  · 一键复制与关闭：气泡右上角提供「📋 复制」与「✕ 关闭」，关闭后仅在新句子到来时才会再次弹出。


六、独立离线工具箱（文档 / 视频 / 图文 / 文本）
────────────────────────────────────────────
首页底部四宫格托盘为离线与日常快译工具，无需依赖实时悬浮窗：

  1. 📄 文档翻译：
     - 支持 6 大主流格式：PDF、Word (docx)、Excel (xlsx)、PowerPoint (pptx)、TXT、Markdown。
     - PDF 逐页高保真排版覆盖：系统级高分辨率渲染，支持「双语交替导出（一页原文一页译文）」与「纯译文覆盖导出」。
     - Word 原位替换：严格保留段落样式、标题层级与表格结构。
     - 导出位置：直接存入系统公共目录 `Download/实时翻译/`，提供系统通知与一键分享/打开。

  2. 🎬 视频翻译与字幕压制：
     - 本地视频音轨提取：高精 SenseVoice 批量断句，生成带准确毫秒级时间戳的字幕条目。
     - 支持「仅识别不翻译」：无需任何 API Key，本地直接提取视频原文字幕。
     - 播放器实时自适应预览：原生比例渲染，支持字体比例、底板透明度、双语颜色个性化调节。
     - 成果交付：
       · 一键导出标准 `.srt` 外挂字幕文件；
       · 原画画质压制（Media3 Transformer 硬件加速）：字幕直接烧录进 MP4 画面底部中央，不降低原视频分辨率。

  3. 📷 相机拍照与 🖼️ 图片相册翻译：
     - 支持即时拍摄或从系统相册选取海报、菜单、说明书。
     - 结构化文字块检测：在原图相应位置覆盖高质量半透明译文色块。
     - 沉浸式对比：支持悬浮「原图/译文」快速对比切换；
     - 自由划选复制：长按文本即可调出系统光标进行自由选词复制，底部提供「复制原文」与「复制译文」。

  4. 📝 快速文本翻译：
     - 适合日常碎片化词句翻译，支持双向一键互换、剪贴板一键粘贴、实时字数统计。

八、语音识别引擎（ASR）全解析
──────────────────────────────
前往「设置 ➔ 核心双引擎 ➔ 语音识别」进行配置与切换：

  1. 本地 SenseVoice（内置 · 推荐）：
     - 阿里通义实验室热门开源模型，内置 int8 离线模型（239MB）。
     - 支持语言：简体中文、英语、日语、韩语、粤语（五语种高精度）。
     - 特性：零流量、零网络依赖、超高 RTF 响应速度；
     - 静音断句调优：默认停顿 0.2s 切句、单句最长 2.0s，语速极快可调低，日常聊天可微调。
  2. 阿里百炼 FunASR（云端流式）：
     - 毫秒级流式 WebSocket 协议，阿里官方 8 大模型全量预设（fun-asr-realtime、paraformer-realtime-v2 等）。
     - 极低延迟，每月提供 10 小时免费额度，适合追求极致精确度的长语音同传。
  3. 通用 OpenAI 兼容 ASR / 云端 Whisper：
     - 支持接入 SiliconFlow（硅基流动免费 SenseVoice）、Groq Whisper、OpenAI 官方 Whisper 等。

十一、常见问题与排错指南
────────────────────────
  Q1：为什么声音同传识别不出声音 / 悬浮窗不跳字？
  A1：
    ① 请检查当前 App 是否被系统静音，或该 App 播放的是受 DRM 保护内容（部分流媒体应用如 Netflix 会在系统底层阻止内录音频）。此时请将声音来源切为「麦克风」，稍开外放即可正常收音；
    ② 检查源语言是否设置正确（如播日语视频，源语言应设为「日语」或「自动」）；
    ③ 若使用的翻译引擎为微软免费版，偶尔可能遇到微软服务端临时限流，切到 DeepSeek 或智谱即可。

  Q2：在第三方应用中，启动翻译时弹出的录屏授权框点不了？
  A2：
    这是 MIUI / HyperOS 或部分定制系统的保护机制。本应用已内置「透明跳板 Activity」，如果偶发遇到点击穿透，先切换回桌面授权一次，之后即可自由使用。

  Q3：屏幕取词画面卡住或不翻译？
  A3：
    ① 检查是否误触了悬浮球导致处于「暂停」状态（点一下悬浮球恢复）；
    ② 屏幕取词帧率经过功耗优化，默认画面有变动且文字稳定时触发识别，属正常省电设计。

  Q4：旋转屏幕后，悬浮窗或取词框位置跑偏？
  A4：
    应用已全面支持屏幕旋转增量映射。旋转屏幕后，悬浮球与外框会自动贴边并重映射物理坐标。若需要微调，点一下悬浮球即可重置选区。

  Q5：遇到未知 Bug 或异常崩溃如何向作者反馈？
  A5：
    前往「设置 ➔ 诊断与支持 ➔ 📊 日志与诊断报告」，点击「分享诊断报告」，系统会自动生成一份已剔除敏感 Key 的匿名脱敏诊断报告（包含机型、系统版本、错误堆栈），可直接通过微信/QQ 发送反馈。
